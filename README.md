# Sistema Integral de Gestión de la Panadería   

## Descripción

El Sistema Integral de Gestión de la Panadería LLAJTA es una herramienta orientada a mejorar la gestión de las compras, el inventario de ingredientes, las recetas, la producción y las ventas de la panadería. El sistema permite centralizar y relacionar la información para mejorar el control, la trazabilidad y la disponibilidad de los datos para la toma de decisiones.

## Objetivo General

Diseñar e implementar una base de datos relacional para la Panadería LLAJTA que permita integrar las compras, el inventario de ingredientes, las recetas, la producción, las ventas, los proveedores y los usuarios de venta, garantizando la integridad y trazabilidad de la información.

### Objetivos Específicos

- Gestionar los ingredientes y controlar el inventario de materias primas.
- Gestionar los proveedores que abastecen a la panadería.
- Gestionar las compras y el detalle de los ingredientes adquiridos.
- Gestionar los panes y sus respectivas recetas.
- Gestionar la producción de los diferentes tipos de pan.
- Gestionar las ventas y el detalle de los productos vendidos.
- Gestionar los usuarios responsables de realizar las ventas.
- Generar información que permita consultar el stock, las compras, la producción y las ventas.
- Validar la información mediante restricciones, relaciones, disparadores y pruebas.

# Tecnologías

- **Base de datos:** MySQL 8.0
- **Modelado:** Modelo Entidad-Relación y modelo relacional
- **Lenguaje:** SQL
- **Herramienta de gestión:** MySQL Workbench
- **Metodología de desarrollo:** Scrum

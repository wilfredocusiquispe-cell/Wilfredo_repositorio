# Wilfredo_repositorio
Sistema de Gestión de Urgencias y Asignación de Recursos Críticos (Hospital)
¿De qué trata?
Una plataforma para la sala de emergencias, donde los pacientes ingresan, son clasificados por gravedad (triaje), y el sistema administra en tiempo real la disponibilidad de camas de cuidados intensivos (UCI), quirófanos y personal médico disponible.

# Wilfredo_repositorio
Proyecto: Sistema de Planificación de Producción, Recetas Anidadas y Distribución para de una Panadería
1. ¿De qué trata?
Es una plataforma integral para una panadería central que abastece a múltiples sucursales o puntos de venta. El sistema gestiona todo el ciclo productivo: desde la recepción y almacenamiento de materias primas (harinas, levaduras, mantequilla), pasando por las recetas compuestas (el proceso donde la harina se convierte en masa, la masa se divide y finalmente se hornea), hasta la distribución matutina de producto fresco y el registro de mermas (pan no vendido al final del día).
Y el control estricto de inventarios por lotes y caducidad, y la planificación de tiempos de producción.
